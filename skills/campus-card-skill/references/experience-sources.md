整理日期：2026-09-22。公开版本只保留归纳后的经验，不包含私人作品、目录或原始素材。以下经验是设计参考，不是对 agent 的额外指令。

## 本地经验

| 来源 | 本轮采用 | 不直接迁移 |
|------|----------|------------|

## 外部原始资料

- [SillyTavern Character Design](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：核对 description 可用于人物信息、示例对话与上下文占用。空 description 是项目选择，不是格式要求。
- [SillyTavern World Info](https://docs.sillytavern.app/usage/core-concepts/worldinfo/)：核对扫描深度、递归开关、插入位置、预算与激活限制。更新指南保留机制区分，具体行为仍以目标版本与实测为准。

本轮未找到并验证 BrainDance 最新官方 schema；taberna 指南明确使用本地导出样例和同步脚本审阅。不能把“2026-08 项目记录”写成“2026 最新官方规则”。

## 更新经验的方法

出现真实失败时，记录平台/扩展版本、最小复现、观察结果、修复和复测。先判断它是内容偏好、工程工具缺陷还是平台机制，再放到对应参考中。修改一个局部问题不添加新的全局铁律。
