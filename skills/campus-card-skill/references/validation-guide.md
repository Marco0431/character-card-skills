# 交付验证与场景回归

按改动规模选择检查。局部文案做结构与内容检查即可；改变触发、状态、导出或 UI 时追加对应测试。没有运行证据就不标“通过”。

## 四个层级

| 层级 | 检查内容 | 能说明什么 |
|------|----------|------------|
| 静态结构 | JSON、字段类型、ID、分类引用、空内容、禁用状态 | 文件内部一致性；不保证平台可导入 |
| 内容审读 | 人设行为、玩家代理权、知情边界、冲突规则、文风 | 设计是否自洽；不等于模型能稳定执行 |
| 场景回归 | 给定前态和输入，检查触发/状态及叙事后果 | 实际跑过的场景表现；手工推演需单独标明 |
| 平台实测 | 导入、提示词查看器、UI、数轮对话/长聊 | 当前版本和配置下的实测结果 |

## 只读审计

```text
python "<skill-dir>/scripts/card-audit.py" "<card.json>"
python "<skill-dir>/scripts/card-audit.py" "<card.json>" --style bai-miao
```

输出 JSON 报告。退出码 0 = 无静态 error（仍可有 warning），1 = 静态 error，2 = 文件读取/JSON 失败。只统计字符，不估 token；不是完整平台 schema 校验器，不求值 EJS，不运行 JS，不模拟世界书检索。未知字段保留并由平台验证。

修改审计工具后运行 `python -B "<skill-dir>/scripts/test_card_audit.py"`。测试覆盖只读性、分类引用、条目 ID、禁用统计、零概率、条件式 NOT、异常结构、文风候选与 CLI 退出码。

本发布版不包含旧生成器、自动写入工具与迁移脚本。工具只读取最大 8 MiB 的本地 JSON，读取失败不打印完整路径或异常原文。

## 最小行为场景

只选与变化相关的场景，每例记录前态、输入、预期、实际、环境及结论：

| 场景 | 预期不变量 |
|------|------------|
| 不填引导页直接开始 | 默认开场可回应，状态有初值 |
| 玩家拒绝邀请/交易 | 不代玩家答应，不结算尚未接受的成本，有可继续的内容 |
| 玩家离场后只说“她” | 不切换为错误角色，必要核心仍可获取 |
| NPC 被问及未在场密谈 | 区分不知道、猜测与已经获得的消息 |
| 再次发现同一线索/重复交付 | 不重复计数或发奖 |
| 重置、跳一天、上下文压缩 | 按字段持久性继承；保留承诺与已知事实 |
| 多角色同场/共用关键词 | 不全员无故抢话，互斥和预算效果正确 |
| 阈值前一档、边界、后一档 | 没有状态空档、重叠或跳级 |
| 玩家声明新事实 / 明确场外改设定 | 分清剧情行动和创作修订；后者同步受影响设定 |
| 引导页复制失败/重置 | 保留手动复制路径，不残留上次选择 |

修状态机制时，至少跑一条跨数轮、包含中断再继续的链路。长聊测试需要真实模型/平台和截断或摘要情境；只读十段设定不能宣称“长聊稳定”。

## 触发与预算

实际检查激活条目以及发送给模型的提示词，而不只检查生成文本“像是触发了”。覆盖命中、误触、漏触、离场失活、连锁激活和预算不足。没有平台时只列测试输入和预期，明确未执行。

## UI 与导出

检查最终 JSON 是否带有脚本、可执行模板或自动加载资源。只静态读取，不打开执行；本技能新建引导内容使用纯文本或 Markdown。保留明确的默认开场与手动操作说明。

重建比较：保持条目身份、扩展和非目标字段；重复构建若出现无缘由 ID 变化，先修构建源。不要为了对齐旧模板清空扩展。

## 交付说明

简述修改、内容源和导出路径、已完成的检查、尚未验证项。遇到现有卡问题只报告任务相关部分；技能改进任务不顺便重写原卡。
