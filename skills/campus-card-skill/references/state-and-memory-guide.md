# 状态、记忆与知情边界

## 定义一份可继承的状态

只为影响下一步的机制建字段。每个字段定义类型、初值、范围/枚举、改变条件、更新责任、可见性和重置规则。叙事、面板、摘要读取同一份结算结果，不分别生成三份数字。

| 字段例 | 更新依据 | 持久性 | 对玩家展示 |
|--------|----------|--------|------------|
| 当前地点、时间 | 实际移动/行动耗时 | 循环时重置 | 可见 |
| 已发现线索 ID 集合 | 首次发现且验证 | 跨循环保留 | 只展示已发现项 |
| 未履约约定 | 明确达成/完成/取消 | 到结清为止 | 玩家知情部分 |
| NPC 对玩家的信任 | 守约、欺骗及其被获知 | 依剧情持续 | 可只显示趋势 |
| 世界真相、NPC 私密目标 | 作者设定与合法剧情变化 | 固定或受控 | 不默认显示 |

精确数值适合钱、库存、线索数量等可验证量；档位适合精力或情绪；自由叙述适合不需要结算的体验。有 MVU/脚本时由实际状态系统校验；纯提示词状态只是尽力遵守，不能声称有数据库级保证。

## 一次行动只结算一次

按“前态 → 已发生的有效行动 → 结果与成本 → 后态”检查。报价不等于成交；意图不等于完成；重复提问不重复发奖。需要抵御刷新、重试或重放时，由执行系统记录事件 ID/已结算标记；纯叙事卡至少记录关键约定的状态。

必要时输出短账本，例如“交付备件，库存 3→2；收款 50，欠款清零”。这是可核查的结果，不是完整内部推演。

关系阈值覆盖边界且不重叠。高信任不覆盖角色底线；拒绝、暂停、反悔是有效选择。结局由已发生的事实与条件判断，多个条件同时成立时写明优先级或给玩家选择。

## 循环与时间跳跃

列出 reset / persist / recompute 字段。重置世界不代表重置所有人的记忆，谁记得需逐人定义。线索用去重集合，数量从集合导出。重开一次只增加一次循环计数。

时间跳跃按用户授权范围推进，保留未履约事项与必要后果；不能为到达预设节点替玩家移动或决定。固定灾难节点可以发生在世界中，同时允许玩家不在场。

## 记忆分层

- **固定档案**：身份、长期动机、已授权的初始关系，不反复抄入每轮事件记忆。
- **当前状态**：位置、在场人物、有效资源和未完成事务，更新必要字段。
- **关键事件摘要**：何时、谁做了什么、结果、谁知道、仍有什么影响。推测标成推测，不压缩成事实。

短期记忆转长期摘要以持续影响为标准，不强制每轮新增。合并日常，保留承诺、转折、证据和未兑现后果。不宣称 HTML 面板、LTM 标签或“永久保留”文字本身能绕过上下文窗口。

## 信息传播与秘密

作者真相供叙述引擎规划；每个角色行动基于其见闻、推测和误信。揭密需具体渠道：目击、转述、证据或主动告知。玩家看到叙述不等于角色知晓。

分离角色内心戏和系统调试信息。悬疑卡只展示玩家已知摘要；折叠面板也不能放未解锁真相。若明确要求全知视角，可以展示戏剧性信息，同时保持角色认知不变。

复测至少包括重复行动、拒绝、跳时/重置，以及不在场角色被问到私密事件的场景。见 [验证方法](validation-guide.md)。
